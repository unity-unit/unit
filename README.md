# SwiftWheels Vehicle Rental & Reservation Subsystem (VRS)

This project contains a Node.js backend and a Vite React frontend for the SwiftWheels VRS application.

## Structure
- `backend/` - Express API, SQLite database, session-based login
- `frontend/` - Vite + React user interface

## Run Locally
1. Start backend:
   - `cd "C:\Users\USER\national exam\backend"`
   - `npm start`
2. Start frontend:
   - `cd "C:\Users\USER\national exam\frontend"`
   - `npm run dev`

## Access
- Frontend: `http://localhost:5173`
- Backend: `http://localhost:4000`

## Login
- Username: `admin`
- Password: `admin123`

## Features
- CRUD for customers, vehicles, reservations
- Search across records
- Session login/logout
- Reservation/rental report with joined data
- Responsive UI powered by Vite React
